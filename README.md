# Gem Miner Tycoon
Idle/clicker game for CrazyGames (single `index.html`, no external assets). Tap the gem, hire miners, buy upgrades, ascend for permanent crystals.
- `node tools/sim.js` pacing simulation; `node tools/test.js` browser smoke test; `python3 tools/package_crazygames.py` builds the zip.
- Ads: midgame after Ascend (≥150 s apart); rewarded only on user request (Boost, Gift ×3, Daily ×2, Offline ×2).
