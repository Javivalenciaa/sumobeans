# Bumper Orbs
Original 2D sumo-arena party game for CrazyGames (single `index.html`, all art and sound generated by code, no external assets).
Push the other orbs off a shrinking platform. Play vs bots, quick-match, or make a private room and invite friends (up to 5 players, bots fill empty seats).

- Controls: WASD / arrows (or drag on touch) to move, Space (or the DASH button) to dash. Pickups: shield, heavy, boost, pulse.
- Match: first to 2 round wins. Coins unlock skins; 📺 rewarded ad doubles the coins. Midgame ad only between matches.
- Languages: English by default, Spanish selectable. Names are auto-generated (no free text → no moderation needed).
- Build: `tools/build.sh` joins `src/part*` into `index.html`. Package: `python3 tools/package_crazygames.py` → `dist/bumper-orbs-crazygames.zip`.
- Tests: `node tools/test_solo.js`, `node tools/test_net.js` (2 browsers + relay, incl. host migration), `node tools/sim_bots.js` (balance).
- Online: host-authoritative. One player's browser simulates; `server/server.js` is a tiny relay (rooms, quick-match, host migration). It is the Sumo Beans relay with a game id (`g`) so both games can share one server. See `docs/SERVER.md`.
